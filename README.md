# SocioGraph

## 📌 About the Project
SocioGraph is an interactive social networking simulation built in C++ using Raylib for the graphical interface. It allows users to sign up, log in, follow other users, search profiles, and explore connections in a visual and interactive environment.
The project demonstrates core Data Structures and Algorithms (DSA) concepts such as:
- Graphs (user connections)
- Breadth-First Search (BFS)
- File handling for persistent storage
- Maps for efficient data management
It simulates basic social media functionality while focusing on efficient relationship management using graph-based structures.

## ✨ Features
- 👤 User registration and login system  
- 🔗 Follow / unfollow functionality  
- 🔍 Search user profiles  
- 🌐 Visual representation of user connections  
- 📊 Graph-based relationship management  
- ⚡ BFS-based exploration of connections  
- 💾 File handling for saving user data

## 🛠️ Technologies Used
- C++  
- Raylib (Graphics Library)  
- Graph Data Structures  
- STL (Maps, Vectors, etc.)  
- File Handling
  
## ⚙️ Setup Instructions
1. Open the Project
- Place the SocioGraph folder on your system
- Open it in Visual Studio Code

2. Install Dependencies
Make sure you have:
- A C++ compiler (GCC / MinGW / MSVC)
- Raylib installed and properly linked

3. Configure Raylib
Ensure Raylib is correctly set up in your development environment so the project can access graphical rendering functions.
Once Raylib is set up, Visual Studio Code can handle the editing, building, and running of the project.

## 🖥️ How It Works
When the program runs:
- A Raylib window opens
- The graphical interface loads
- Users can interact with the system (login, follow, search, etc.)
- The system continuously updates using Raylib’s rendering loop
